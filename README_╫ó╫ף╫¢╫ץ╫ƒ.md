# קבצים מעודכנים — "מילים שבוראות שנה"
החליפי כל קובץ בריפו בנתיב הזהה, ואז commit + push (נטליפיי יבנה אוטומטית):

- src/App.tsx — ניווט לחיץ בין תחנות, כותרת כוונה חדשה, מסגרת "הידעת?", קישורי מדורים, פוטר
- src/components/Facilitator.tsx — מקורות אקדמיים + מחיקות (סעיפים 4–8)
- src/components/PersonalCard.tsx — הדגשת כל המילים באיחול, "כתיבה וחתימה" מוגדל
- src/data/intentions.ts — 13 משפטי כוונה חדשים מהמאגר
- src/lib/weave.ts — ממשק מורחב + תבנית גיבוי עשירה
- src/styles.css — בולים מיושרים, מסגרת "הידעת?", פוטר עגול, הדגשות
- netlify/functions/weave.mjs — פרומפט Gemini משודרג (40–60 מילים, עומק ופידבק)

⚠️ חדש: כל מנחה יכול להשתמש בלוח פאדלט משלו! בדף "מדריך למנחה" נוסף מחולל קישור אישי.
הדביקי בהם את קישורי ה-Breakout מהפאדלט (הסבר בצ'אט ובמדריך למנחה).
