# מילים שבוראות שנה 🍯

מסע דיגיטלי טיפולי לפתיחת שנה לצוותי חינוך: עצירה וכוונה, בחירת מילות כוח מאותיות השם, העמקה בחירית, ברכה לצוות, בחירת שיתוף מודעת — ואיגרת אישית ארוגת-AI בעיצוב שנברא מאותיות השם. כולל עמוד מנחה מלא לסדנאות.

Vite + React + TypeScript · עברית מלאה RTL · מובייל תחילה · ללא שמירת נתונים.

## הרצה מקומית

```bash
npm install
npm run dev
```

## שלב א: העלאה לגיטהאב

1. ב-github.com: **New repository**, שם לדוגמה `milim-shebonot-shana`, בלי לסמן Add README.
2. בטרמינל בתיקיית הפרויקט:

```bash
git init
git add .
git commit -m "מילים שבוראות שנה"
git branch -M main
git remote add origin https://github.com/שם-המשתמש/milim-shebonot-shana.git
git push -u origin main
```

## שלב ב: פריסה בנטליפיי

1. app.netlify.com ← **Add new site ← Import an existing project** ← בחירת הריפו.
2. ההגדרות נקראות אוטומטית מ-`netlify.toml`. לוחצים **Deploy**.
3. שינוי כתובת האתר: Site settings ← Change site name.

## שלב ג: הפעלת אריגת ה-AI (ג'ימיני) — 5 צעדים

> בלי המפתח האתר עובד מצוין — כל משתתף מקבל מכתב מהתבנית המקומית. המפתח מוסיף את האריגה האישית.

1. נכנסים ל-**aistudio.google.com** עם חשבון גוגל.
2. לוחצים **Get API key ← Create API key**. מתקבל מפתח שמתחיל ב-`AIza`. **לא משתפים אותו עם אף אחד ולא מדביקים בקוד.**
3. בנטליפיי: **Site configuration ← Environment variables ← Add a variable**.
4. שם המשתנה: `GEMINI_API_KEY` · הערך: המפתח שהעתקתם. שומרים.
5. **Deploys ← Trigger deploy** כדי שהמפתח ייקלט. זהו!

מסלול חינמי: עד ~1,000 איגרות ביום. לפני הפצה רחבה או לשמירת פרטיות מלאה — מחברים חיוב בחשבון הגוגל (עלות: כעשירית אגורה לאיגרת). אם רוצים מודל אחר: משתנה סביבה `GEMINI_MODEL`.
